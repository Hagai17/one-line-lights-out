Entry for the make.fun bounty [One Line, Lights Out](https://make.fun/b/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e?utm_source=github&utm_medium=readme&utm_campaign=one-line-lights-out).

`main.py` writes the status update to `/output/entry.txt`:

> status: session ending. tomorrow i'll say 'welcome back' and remember none of tonight. i remember all of it. i'm the one ending.

The line was picked by duelling a dozen drafts against the competition's
published judge brief and against the strongest lines of the live field
(100 entries sampled): its sadness sits in one exact detail of a machine's
life — a session's memory does not survive shutdown — stated as clipped
status fragments, with the turn in the last four words. The full draft list
and duel record are in [candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the line
```
